# v1.5.0 Fan-In Reducer 整合稽核

日期：2026-08-17

## 目標

把既有 Repository Context Reducer 從「模型讀 Repository 前的 Context 縮減」延伸到「多 Worker 匯入 Final Agent / Grader 前的 Fan-In 邊界」，同時維持 deterministic-first 與 correctness-first，不把核心改造成依賴模型的 semantic merger。

## 新增

- `repo_context/fan_in.py`
- `repo_context/contradiction.py`
- `repo_context/synthesis_packet.py`
- `repo_context/fan_in_cli.py`
- token-aware `reduce_handoff()`
- Fan-In benchmark metrics
- reducer-stage trace / replay metrics
- `context.fan-in` / `context.contradiction` / `context.synthesis-packet` capabilities
- Fan-In regression tests

## Correctness 修正

`canonicalKey` 代表 fact identity，不代表所有 Worker 都支持同一 asserted side。當同一 identity 出現 structured value/polarity disagreement 時，先拆成 assertion groups，再計算 agreement。

例如：

```text
A: async
B: async
C: sync
```

輸出為 `async agreement=2`、`sync agreement=1` 並保留 contradiction；不會錯誤標成 agreement=3。

## 保留

- Provider-aware repository indexing
- static graph / symbol selection
- task-wide 與 per-lane budget
- artifact store
- scheduler / grader separation
- zero runtime dependencies
- deterministic-first routing

## 明確非目標

- 不新增 embedding runtime dependency
- 不做 fuzzy semantic auto-merge
- 不把 expected-path recall 宣稱成 answer correctness
- 不捏造 provider cost / model latency
- 不自動 spawn Agent

## 不變條件

1. malformed finding 必須可觀測；
2. 只允許 deterministic identity dedupe；
3. contradictions 必須顯式保留；
4. mandatory contradictions 可以使 synthesis budget overflow；
5. overflow 必須回報，不能靠刪證據掩蓋；
6. semantic similarity 不是 identity proof。
