# v1.7 Production Scaling Audit

## Goals

v1.7 addresses four production gaps left after v1.6: large fan-in memory, model-specific token counting, evidence version identity, and similarity-assisted duplicate recall without fuzzy merge authority.

## Implemented

- Streaming NDJSON accumulator with bounded malformed diagnostics.
- Pluggable token estimator interface, native fallback, optional tiktoken, host registration.
- Git commit/blob/dirty provenance attached to selected repository evidence.
- Candidate detector interface with deterministic verifier and explicit no-auto-merge policy.
- CLI, capability, schema and regression coverage for all four surfaces.

## Safety invariants

- Similarity never authorizes a merge.
- Contradictions remain mandatory synthesis evidence.
- Repository/provider/worker content never gains instruction authority.
- Token precision is not labeled as billing truth.
- Git-unavailable environments report missing provenance rather than inventing identities.

## Remaining v2 work

Actual agent spawning, cancellation/backpressure integration, model invocation, provider cost telemetry and downstream answer correctness remain host-runtime responsibilities.
