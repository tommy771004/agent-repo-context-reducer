# v1.6 Context Contracts

The normative machine-readable contracts live under `repo_context/schemas/` and use JSON Schema Draft 2020-12.

Contracts:

- `finding.schema.json`
- `worker-output.schema.json`
- `handoff.schema.json`
- `fan-in.schema.json`
- `contradiction.schema.json`
- `synthesis-packet.schema.json`
- `trace-event.schema.json`
- `benchmark-case.schema.json`

The project remains dependency-free at runtime. `repo-context schema validate` checks stable invariants required by this implementation; hosts may use a complete Draft 2020-12 validator for full schema evaluation.

Compatibility rule: schemas follow actual runtime payloads. Field renames are not introduced merely to make a new contract prettier. Additive fields are preferred within a schema major version.
