# v1.6 Production Boundary Audit

## Scope

v1.6 hardens the boundaries between repository/provider data, parallel worker outputs, deterministic reduction and final-model synthesis.

## Added

- Formal Draft 2020-12 payload contracts.
- Dependency-free contract invariant validation.
- Main CLI Fan-In and Synthesis Packet commands.
- Untrusted-content labeling and prompt-injection-like signal detection.
- Deterministic worker-to-synthesis-packet correctness benchmarks.
- Orchestration capability declarations for schemas, trust boundary and reducer benchmarking.

## Deliberate non-claims

- Trust scanning is not a sandbox or proof of safety.
- UTF-8 bytes / 4 remains an estimate, not model billing tokens.
- Deterministic E2E fixtures do not measure downstream LLM answer correctness.
- The harness planner still does not spawn or cancel agents without an external runtime adapter.
- Semantic similarity still has no merge authority.

## Next boundary

v1.7 should focus on streaming/NDJSON fan-in, pluggable tokenizers, Git/blob provenance and semantic candidate detection with deterministic verification.
